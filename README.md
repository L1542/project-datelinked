# Music Playlist Management System

โปรแกรมจัดการเพลย์ลิสต์เพลงบน Command Line เขียนด้วยภาษา Java โดยใช้โครงสร้างข้อมูลแบบ **Doubly Linked List** (ลิงก์ลิสต์สองทิศทาง) ไม่ใช้ `ArrayList` หรือ `LinkedList` ของ Java เพื่อให้เห็นการทำงานของโครงสร้างข้อมูลจริง ๆ

## ภาพรวมโปรแกรม

| เมนู | ฟังก์ชัน | รายละเอียด |
|------|----------|------------|
| 1 | Add | เพิ่มเพลงต่อท้ายเพลย์ลิสต์ (กรอกชื่อเพลง) |
| 2 | Delete | ลบเพลงตามชื่อ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) |
| 3 | Search | ค้นหาเพลงตามชื่อ แสดงชื่อเพลงและลำดับที่ ค้นซ้ำได้จนกว่าจะกด Enter เพื่อย้อนกลับ |
| 4 | Next/Previous | เลื่อนไปเพลงถัดไปหรือก่อนหน้า พร้อมแสดงรายการเพลงทั้งหมดและเพลงที่กำลังเล่น |
| 0 | ปิดโปรแกรม | ออกจากโปรแกรม |

จุดเด่น:

- จำตำแหน่งเพลงที่กำลังเล่นไว้ ออกจากเมนู Next/Previous แล้วกลับเข้ามาก็ยังอยู่เพลงเดิม
- ตรวจสอบ input ทุกจุด ไม่ว่าจะเป็นค่าว่าง ตัวอักษรแทนตัวเลข เลขนอกช่วง หรือชื่อซ้ำ
- ออกจากโปรแกรมอย่างปลอดภัยแม้ input ถูกปิดกลางทาง (Ctrl+D / Ctrl+Z)
- มีตัวกัน error ที่ไม่คาดคิดครอบการทำงานของเมนู โปรแกรมจะไม่ปิดตัวเอง

## วิธีรัน

### โครงสร้างโฟลเดอร์

```
src/musicplaylist/MusicPlaylist.java
```

### คอมไพล์และรัน

```bash
javac -encoding UTF-8 -d out src/musicplaylist/MusicPlaylist.java
java -Dfile.encoding=UTF-8 -cp out musicplaylist.MusicPlaylist
```

| ส่วนของคำสั่ง | ความหมาย |
|----------------|----------|
| `-encoding UTF-8` | บอกคอมไพเลอร์ให้อ่านซอร์สโค้ดเป็น UTF-8 (มีข้อความภาษาไทยในโค้ด) |
| `-d out` | เก็บไฟล์ `.class` ไว้ในโฟลเดอร์ `out` |
| `-Dfile.encoding=UTF-8` | ให้ JVM ใช้ UTF-8 ตอนรับและแสดงผล |
| `-cp out` | บอกตำแหน่งของไฟล์ `.class` |

### กรณีภาษาไทยแสดงผลเพี้ยน

**Windows (Command Prompt):** รันคำสั่งนี้ก่อนรันโปรแกรม

```
chcp 65001
```

**IDE (NetBeans, IntelliJ IDEA):** ตั้ง encoding ของโปรเจกต์เป็น UTF-8 แล้วรันจาก IDE

## วิธีใช้งานแต่ละเมนู

เมื่อเปิดโปรแกรม จะแสดงเมนูหลัก

```
-----------
เพลย์ลิสต์เพลง
1. Add
2. Delete
3. Search
4. Next/Previous
0. ปิดโปรแกรม
-----------
เลือกเมนู :
```

> ทุก input จะถูกตัดช่องว่างหน้า-หลัง (`trim`) ก่อนนำไปใช้

### 1. Add: เพิ่มเพลง

```
เลือกเมนู : 1
กรอกชื่อเพลง : Shape of You
เพิ่มเพลง "Shape of You" สำเร็จ
```

- เพลงใหม่จะถูกต่อท้ายเพลย์ลิสต์เสมอ
- เพลงแรกที่เพิ่มจะกลายเป็นเพลงที่กำลังเล่นโดยอัตโนมัติ
- ถ้าชื่อว่าง ยาวเกิน 100 ตัวอักษร หรือซ้ำกับที่มีอยู่ จะแจ้ง error แล้วกลับเมนูหลัก

### 2. Delete: ลบเพลง

```
เลือกเมนู : 2
กรอกชื่อเพลงที่ต้องการลบ : shape of you
ลบเพลง "Shape of You" สำเร็จ
```

- พิมพ์ตัวเล็ก/ใหญ่อย่างไรก็ได้ แต่ข้อความที่แสดงหลังลบจะเป็นชื่อเพลงตามที่บันทึกไว้จริง
- ถ้าเพลย์ลิสต์ว่างจะแจ้ง error ทันทีโดยไม่ถามชื่อเพลง
- ถ้าลบเพลงที่กำลังเล่น เพลงปัจจุบันจะเลื่อนไปเพลงถัดไป ถ้าไม่มีเพลงถัดไปจะถอยไปเพลงก่อนหน้า

### 3. Search: ค้นหาเพลง

```
เลือกเมนู : 3
ค้นหาเพลง (กด Enter เพื่อย้อนกลับ) : blinding lights
พบเพลง!
ชื่อเพลง : Blinding Lights
ลำดับที่  : 2
```

- ต้องพิมพ์ชื่อเพลงให้ตรงทั้งชื่อ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) ไม่ใช่การค้นหาแบบบางส่วนของชื่อ
- ถ้าไม่พบ จะให้กรอกใหม่ได้เรื่อย ๆ จนกว่าจะพบ หรือกด Enter เพื่อย้อนกลับ
- เมื่อพบเพลงแล้วจะกลับเมนูหลักทันที

### 4. Next/Previous: เลื่อนเพลง

```
---- เพลย์ลิสต์ ----
1. Shape of You  <--- กำลังเล่น
2. Blinding Lights
--------------------
กำลังเล่น : Shape of You
[N] Next  [P] Previous  [B] Back :
```

| คำสั่ง | การทำงาน |
|--------|----------|
| `N` | ไปเพลงถัดไป (ถ้าเป็นเพลงสุดท้ายจะแจ้ง "นี่คือเพลงสุดท้ายแล้ว") |
| `P` | ไปเพลงก่อนหน้า (ถ้าเป็นเพลงแรกจะแจ้ง "นี่คือเพลงแรกแล้ว") |
| `B` | กลับเมนูหลัก |

- พิมพ์ตัวเล็กหรือตัวใหญ่ก็ได้ (`n` / `N`)
- ถ้าเพลย์ลิสต์ว่างจะแจ้ง error แล้วกลับเมนูหลัก
- หน้านี้จะแสดงรายการเพลงทั้งหมดใหม่ทุกครั้งที่กดคำสั่ง

### 0. ปิดโปรแกรม

```
เลือกเมนู : 0
ลาก่อน!
```

> ข้อมูลเพลย์ลิสต์เก็บอยู่ในหน่วยความจำเท่านั้น เมื่อปิดโปรแกรมข้อมูลจะหายทั้งหมด

## โครงสร้างข้อมูล: Doubly Linked List

แต่ละเพลงเป็น `Node` ที่มีตัวชี้ไปทั้งเพลงก่อนหน้า (`prev`) และเพลงถัดไป (`next`)

```
null <- [Node A] <-> [Node B] <-> [Node C] -> null
          head                       tail
```

- `Node` เก็บ `title`, `prev`, `next`
- `Playlist` เก็บตัวชี้ `head` (เพลงแรก), `tail` (เพลงสุดท้าย), `current` (เพลงที่กำลังเล่น) และ `size` (จำนวนเพลง)

### การเพิ่ม (ต่อท้าย)

```
ก่อน:    head -> [A] <-> [B] <- tail
เพิ่ม C
หลัง:    head -> [A] <-> [B] <-> [C] <- tail
```

ใช้ `tail` ชี้ไปท้ายรายการได้เลย จึงไม่ต้องวนหาตำแหน่ง ใช้เวลา O(1)

### การลบ

กรณีลบ Node ตรงกลาง ให้ Node ก่อนหน้าและถัดไปชี้ข้ามกัน

```
ก่อน:    [A] <-> [B] <-> [C]
ลบ B
หลัง:    [A] <-> [C]
```

โค้ดจัดการครบทุกกรณี

| กรณี | สิ่งที่ทำ |
|------|-----------|
| ลบ Node ตรงกลาง | `n.prev.next = n.next` และ `n.next.prev = n.prev` |
| ลบ `head` | ย้าย `head` ไปที่ `n.next` |
| ลบ `tail` | ย้าย `tail` ไปที่ `n.prev` |
| ลบเพลงที่กำลังเล่น | `current` ไปที่ `n.next` ถ้าไม่มีให้ไปที่ `n.prev` |
| ลบเพลงสุดท้ายที่เหลืออยู่ | `head`, `tail`, `current` เป็น `null` และ `size` เป็น 0 |

หลังลบจะตัดตัวชี้ของ Node ที่ถูกลบ (`n.prev = n.next = null`) เพื่อให้ garbage collector เก็บคืนได้

## โครงสร้างโค้ด

ทุกอย่างอยู่ในไฟล์เดียว `MusicPlaylist.java` แบ่งเป็นส่วนต่อไปนี้

### คลาสภายใน

| คลาส | หน้าที่ |
|------|---------|
| `Node` | เก็บข้อมูลเพลงหนึ่งเพลง (`title`) และตัวชี้ `prev`, `next` |
| `Playlist` | จัดการลิงก์ลิสต์ ได้แก่ เพิ่ม ค้นหา ลบ และแสดงรายการ |
| `InputClosedException` | Exception ที่โยนเมื่อ input ถูกปิด ใช้สั่งให้โปรแกรมออกอย่างปลอดภัย |

### เมธอดของ `Playlist`

| เมธอด | หน้าที่ |
|-------|---------|
| `add(String title)` | เพิ่มเพลงต่อท้าย (โยน `IllegalArgumentException` ถ้าชื่อว่าง) |
| `search(String title)` | ค้นหา Node ตามชื่อแบบไม่สนตัวพิมพ์เล็ก/ใหญ่ คืน `null` ถ้าไม่พบ |
| `indexOf(Node target)` | คืนตำแหน่ง (เริ่มจาก 0) ของ Node ที่ระบุ หรือ -1 ถ้าไม่พบ |
| `delete(Node n)` | ลบ Node ที่ระบุ (โยน `IllegalArgumentException` ถ้าเป็น `null`) |
| `isEmpty()` | คืน `true` ถ้าไม่มีเพลง |
| `print()` | แสดงรายการเพลงพร้อมลำดับและเครื่องหมาย `<--- กำลังเล่น` |

### เมธอดของโปรแกรมหลัก

| เมธอด | หน้าที่ |
|-------|---------|
| `readLine()` | อ่านบรรทัดจาก input และตัดช่องว่าง โยน `InputClosedException` ถ้า input ปิด |
| `showMenu()` | แสดงเมนูหลัก |
| `addSong()` / `deleteSong()` / `searchSong()` / `nextPrevious()` | ทำงานของแต่ละเมนู |
| `main()` | วนลูปรับคำสั่งและเรียกเมนูตามที่เลือก |

## ความซับซ้อนของเวลา

| การทำงาน | Time Complexity | เหตุผล |
|----------|-----------------|--------|
| Add (ต่อท้าย) | O(1) | มีตัวชี้ `tail` อยู่แล้ว (ไม่นับการเช็กชื่อซ้ำก่อนเพิ่ม ซึ่งเป็น O(n)) |
| Search | O(n) | ต้องวนเทียบชื่อทีละ Node |
| Delete (รวมการค้นหา) | O(n) | การค้นหาเป็น O(n) ส่วนการตัด Node ออกเป็น O(1) |
| Next / Previous | O(1) | ใช้ตัวชี้ `next` / `prev` ของ `current` โดยตรง |

## กฎและการดัก Error

### การตรวจสอบชื่อเพลง

| เงื่อนไข | ข้อความที่แสดง |
|----------|----------------|
| ชื่อว่าง | `ผิดพลาด: ชื่อเพลงว่างเปล่า` |
| ยาวเกิน 100 ตัวอักษร | `ผิดพลาด: ชื่อเพลงยาวเกินไป (สูงสุด 100 ตัวอักษร)` |
| ซ้ำกับเพลงที่มีอยู่ (ไม่สนตัวพิมพ์เล็ก/ใหญ่) | `ผิดพลาด: มีเพลง "..." อยู่ในเพลย์ลิสต์แล้ว` |

### การตรวจสอบเมนู

| เงื่อนไข | ข้อความที่แสดง |
|----------|----------------|
| ไม่กรอกอะไรเลย | `ผิดพลาด: กรุณากรอกตัวเลข` |
| กรอกตัวอักษรหรือข้อความที่ไม่ใช่ตัวเลข | `ผิดพลาด: "..." ไม่ใช่ตัวเลขที่ถูกต้อง` |
| ตัวเลขนอกช่วง 0-4 | `ผิดพลาด: เลขไม่ถูกต้อง เลือกได้ 0-4` |

### การตรวจสอบอื่น ๆ

| เงื่อนไข | พฤติกรรม |
|----------|----------|
| Delete / Search / Next-Previous ตอนเพลย์ลิสต์ว่าง | แจ้ง `ผิดพลาด: เพลย์ลิสต์ว่างเปล่า` แล้วกลับเมนูหลัก |
| Delete หรือ Search ไม่พบเพลง | แจ้ง `ผิดพลาด: ไม่พบเพลง "..."` (Search จะให้กรอกใหม่) |
| คำสั่งใน Next/Previous ไม่ใช่ N, P, B | แจ้ง `ผิดพลาด: คำสั่งไม่ถูกต้อง ให้ใช้ N, P หรือ B` |
| Input ถูกปิดกลางทาง (Ctrl+D / Ctrl+Z) | แสดง `ปิดการรับข้อมูลแล้ว ลาก่อน!` แล้วออกอย่างปลอดภัย |
| Error ที่ไม่คาดคิด (`RuntimeException`) | แสดงข้อความ error แล้วกลับเมนูหลัก โปรแกรมไม่ปิดเอง |

## ข้อสังเกตและข้อจำกัด

- ข้อมูลไม่ถูกบันทึกลงไฟล์ ปิดโปรแกรมแล้วเพลย์ลิสต์จะว่างเปล่า
- การค้นหาและการลบต้องใช้ชื่อเต็มของเพลง ไม่รองรับการค้นหาบางส่วนของชื่อ
- ไม่มีการเล่นเพลงจริง `current` เป็นเพียงตัวชี้ตำแหน่งที่จำลองว่ากำลังเล่น
- เก็บเฉพาะชื่อเพลง ไม่มีข้อมูลอื่น เช่น ศิลปิน หรือความยาวเพลง
